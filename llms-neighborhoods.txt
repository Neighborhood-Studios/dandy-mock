# Dandy neighborhoods & service areas

Dandy serves select neighborhoods in metropolitan Atlanta, including:
- Decatur and Oakhurst
- Brookhaven
- Buckhead
- Virginia-Highland
- Morningside
- Druid Hills
- Midtown
- Inman Park
- Kirkwood
- East Atlanta
- Grant Park
- Candler Park
- Lake Claire
- Tucker
- Avondale Estates
- Scottdale
- Stone Mountain
- North Decatur

Availability is determined by the homeowner's ZIP code and Dandy's current service capacity. Each Dandyman is dedicated to about 50 homes in one neighborhood, so the same person visits every time.

## How Dandy launches a neighborhood ("drops")
Dandy opens a neighborhood in a drop: 50 memberships become available on a set drop day, each starting with a free home walk-thru. Homeowners join the neighborhood waitlist beforehand and book on drop day at https://hidandy.com/drop-day. Once the 50 spots are taken, the page shows a sold-out state and Dandy reaches out when more spots open.
